# LOL 自动录制工具

检测英雄联盟游戏进程，自动控制 OBS 录制。开局自动录制，游戏结束自动停止。

## 功能

- 🎮 自动检测游戏进程，智能启停录制
- 🖥️ 图形化界面，一键启停
- ⚙️ 界面内直接修改配置参数
- 📝 实时日志输出
- 💡 OBS 连接状态 + 录制状态指示灯
- 🔔 系统托盘，关闭窗口后台运行

## 安装

```bash
pip install -r requirements.txt
```

## 使用

```bash
python main.py
```

### OBS 配置

1. 打开 OBS → 工具 → WebSocket 服务器设置 → 启用
2. 在 GUI 的参数配置中填入 OBS 密码
3. 点击「保存配置」

### 音频方案（推荐）

在 OBS 场景中添加：

| 源类型 | 名称 | 音轨 |
|--------|------|------|
| 应用音频采集 | 游戏音频（绑定 LOL） | 音轨 1 |
| 音频输出采集 | 桌面音频 | 音轨 2 |
| 音频输入采集 | 麦克风 | 音轨 2 |

录制结果：音轨 1 = 纯游戏声，音轨 2 = 全部声音 + 你的麦克风。

## 工作原理

```
[GUI 主线程]  ←→  [Recorder 后台线程]
                     │
                     ├── psutil 每 3 秒检测进程
                     ├── obsws-python 控制 OBS
                     └── 状态机：IDLE → WAITING → RECORDING → COOLDOWN
```
